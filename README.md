# Кварта — веб-сайт

**Демо:** https://kvarta-ecru.vercel.app/  
**Репозиторий:** https://karinakit.github.io/Kvarta/public/index.html

## О проекте

«Кварта» — веб-проект, разработанный в рамках тестового задания. В процессе работы я реализовала структуру и оформление сайта, настроила обработку формы отправки заявок и интеграцию с Telegram Bot API для получения уведомлений.

Проект помог мне закрепить практические навыки разработки клиентской и серверной частей веб-приложения, работы с API и публикации сайта.

## Используемые технологии

- **HTML5** — структура страниц.
- **CSS3** — оформление и стилизация интерфейса.
- **JavaScript** — логика взаимодействия с пользователем и обработка формы.
- **Node.js** — серверная среда выполнения.
- **Express** — обработка серверных запросов.
- **Telegram Bot API** — отправка уведомлений о заявках.
- **Git и GitHub** — контроль версий и хранение исходного кода.
- **Vercel** — развёртывание проекта.

## Функциональность

- Отображение содержимого сайта.
- Обработка отправки заявок через форму.
- Передача данных с клиентской стороны на сервер.
- Отправка уведомлений о заявках в Telegram.
- Обработка запросов с использованием серверной части приложения.

## Процесс разработки

Работу над проектом я выполняла поэтапно, сохраняя изменения в Git и отправляя их в GitHub. Это позволило отслеживать историю разработки и возвращаться к предыдущим версиям кода при необходимости.

В процессе работы я занималась структурой и оформлением сайта, реализацией логики формы, настройкой серверной части и интеграцией с Telegram Bot API. После разработки проверяла работу сайта локально, тестировала отправку заявок и проверяла результат на опубликованной версии.

## Работа с ИИ

Во время разработки я использовала ИИ как помощника для изучения новых технологий, анализа кода, поиска ошибок и настройки серверной части.

Одной из сложностей стала нестабильная отправка заявок в Telegram. Сайт отображал успешный результат отправки формы, однако уведомления в Telegram иногда не поступали.

Я обратилась к ИИ, чтобы разобраться в возможной причине проблемы. В ходе анализа мы рассмотрели серверный код, формирование HTTP-запроса к Telegram Bot API и заголовки `Content-Type` и `Content-Length`. ИИ помог мне разобраться с проблемой и исправить ошибку. После внесения изменений я повторно протестировала форму и проверила получение уведомлений.

Также я использовала ИИ при решении технических вопросов, связанных с настройкой серверной части и публикацией проекта на Vercel.

Предложенные решения я проверяла на практике: запускала проект, анализировала сообщения в терминале и тестировала фактическую отправку данных.

## Тестирование и отладка

В процессе разработки я проверяла:

- корректность отображения сайта;
- работу формы отправки заявок;
- передачу данных между клиентской и серверной частями;
- отправку уведомлений в Telegram;
- работу опубликованной версии сайта.

При возникновении ошибок я анализировала поведение приложения, проверяла код и использовала ИИ для поиска возможных причин и вариантов исправления.

В дальнейшем планирую уделить больше внимания автоматизированному тестированию, проверке негативных сценариев и обработке ошибок, а также провести аудит производительности и доступности с помощью Lighthouse.

## Развёртывание

Проект опубликован на Vercel.

Для работы интеграции с Telegram необходимо настроить соответствующие переменные окружения в настройках проекта.

Названия переменных окружения следует сверить с используемыми в серверном коде. Токен Telegram-бота и другие секретные данные не должны храниться в публичном репозитории.
